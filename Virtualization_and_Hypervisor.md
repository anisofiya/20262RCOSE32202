Virtualization

- Allows one physical computer to run multiple virtual machines (VMs).
- Improves hardware utilization by sharing physical resources.
- **Consolidation** : Combines multiple systems onto fewer physical machines which helps reduce hardware costs.
- **Isolation** : Each VM operates independently that can improves isolation and reliability.

Hypervisor

- Software that creates and manages VMs and allocates hardware resources.
- **Type 1** : Runs directly on physical hardware
- **Type 2** : Runs on top of host OS

Advantage : Efficient resource utilization

Disadvantage : Additional virtualization overhead may reduce performance

Performance Improvements:

- Paravirtualization
- Acceleration with hardware supports
